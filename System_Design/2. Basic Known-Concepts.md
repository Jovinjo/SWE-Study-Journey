### 1.3. DNS (Domain Name System)

<img width="736" height="106" alt="image" src="https://github.com/user-attachments/assets/040f33c5-6557-455f-bfec-7ee9c60c04ad" />

It allows us to type "Google.com" instead of IP-Address. How does it usually check which domain belongs to which IP?

- First browser check local cache.
- If not there ask DNS resolver > it queries root server > then top-level domain server (.com, .org) > authoritative name server give the domain name > the result gets cached in every request

### 1.4. Proxy vs Reverse Proxy

A proxy is the middleman between client and server.

- Forward Proxy<br />
It hides the client's identity from the server > For example like VPN / company proxy > Helps for privacy.

<img width="651" height="274" alt="image" src="https://github.com/user-attachments/assets/a84e4830-aff3-4dfd-90a0-156127cebe10" />

- Reverse Proxy <br />
It hides the server's identity from the client > For example Nginx and HAProxy > The client thinks it talks to to one server, but the proxy rout the request to multiple backend servers

<img width="664" height="272" alt="image" src="https://github.com/user-attachments/assets/cd8b3d43-0546-4b66-a937-fd23afdb626e" />

### 1.5. Latency

<img width="459" height="213" alt="image" src="https://github.com/user-attachments/assets/8d461003-285e-487f-bfc9-e0f0cdd4f877" />

Latency (Speed) comes from different factors:

- Network distance
- Serialization = Converting data to bytes
- Processing time on the server
- Queue delay because server busy

### 1.6. HTTP/HTTPS

HTTP is language that clients and servers use to communicate on the web. It tells how request and response should be structured. HTTPS is the encrypted version with TLS for better protection of data.

<img width="384" height="601" alt="image" src="https://github.com/user-attachments/assets/06e47351-a73b-43b6-beca-08e839c496c7" />

HTTP is stateless -> It means it does not save history of previous request / response. <br /> Therefore we need cookie, tokens, or sessions to maintain the history requests.
